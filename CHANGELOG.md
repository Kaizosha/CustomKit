# Changelog

All notable changes to Kaizōsha’s CustomKit are recorded here.

## Unreleased

- Added the CustomKit catalog with 16 interactive examples and individual customization sheets.
- Added reusable Kaizōsha branding, launch and start templates, liquid rows, action buttons, switchers, segments, haptic sheets, credits, playback controls, captions, and pull-to-clear.
- Added a runnable example app with real PlayerKit, CaptionKit, and Sekai integrations.
- Organized the public package by component domain and preserved the existing slider API.
- Added caption timing, pull-state, and catalog interaction checks.

## 0.2.0 — 2026-07-30

- Renamed the public control to `Slider`.
- Renamed its customization types to `SliderStyle` and `SliderDirection`.
- Renamed the source, tests, and documentation to match the public API.

## 0.1.0 — 2026-07-30

- Added the initial SwiftUI control with drag-only discrete selection.
- Added configurable appearance and layout direction.
- Added customizable accessibility labels and value descriptions.
- Added editing-state callbacks, haptic feedback, and vertical fine scrubbing.
- Added Swift Testing coverage and DocC integration guidance.
