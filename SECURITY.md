# Security policy

Security fixes apply to the current `main` branch of KaizoshaInterfaceKit.

Do not open a public issue for a suspected vulnerability. Contact Kaizōsha through [kaizosha.org](https://kaizosha.org) with reproduction steps, the affected commit, and the expected impact.

KaizoshaInterfaceKit has no networking, persistence, analytics, or external package dependencies. Device-motion samples remain in memory and stop when the logo is no longer visible or active.
